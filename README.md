## 🇹🇷 Türkçe Açıklama ve Kurulum

**AI Local Translator**, bilgisayarınızdaki yerel **Ollama** yapay zeka modellerini kullanarak internet kotası veya karakter sınırı olmadan çeviri yapmanızı sağlar.

1. **[AI Local Translator sürüm sayfasından](https://github.com/etemcankvrc/local-AI-tools/releases/tag/AI-Local-Translator)** `AI_Local_Translator_Setup_v1.0.11_FREE.zip` veya `AI_Local_Translator_FullStage_v1.0.11_FREE.zip` dosyasını indirin.
2. ZIP dosyasını açıp içindeki kurulum/uygulama dosyasını çalıştırın. **Setup** sürümü bilgisayarınızda **Ollama** kurulu değilse otomatik olarak indirip kurar.
3. Uygulama açıldığında **6. Bölümden** (`gemma2:9b`, `aya-expanse:8b` veya `qwen2.5:7b`) dilediğiniz modeli tek tıkla indirip çeviriye başlayabilirsiniz.
